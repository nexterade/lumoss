      · Ada komentar inline setelah command

  📌 CONTOH SALAH:

    cd /storage/emulated/0/Project/lumoss
    # Pindah ke folder project          ← ❌ INI SALAH!
    git status
    git add -A                          ← ❌ ada komentar di atas

  📌 CONTOH BENAR:

  ✅ ATURAN YANG BENER:

  🎯 SELF-CHECK SEBELUM KIRIM COMMAND:
