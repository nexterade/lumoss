Dibuat dengan lumoss — Media Garden

✨ v7.2.11 · Luminous Moss Edition

📖 Tentang Project

lumoss adalah tool untuk upload otomatis foto/video ke Catbox.moe, generate galeri HTML interaktif, dan deploy ke GitHub Pages — semuanya dari terminal.

Dibuat untuk koleksi media pribadi tanpa konfigurasi hosting rumit. Cukup taruh file di folder media, jalankan lumoss, dan dashboard web siap ditayangkan.

✨ Fitur Utama

👥
Multi-Account
Kelola banyak akun Catbox dengan folder terisolasi
🏷️
Auto-Tag
Tag otomatis dari nama file, folder, & EXIF metadata
🖼️
Thumbnail Pintar
WebP untuk gambar, JPG untuk video via FFmpeg
🎨
6 Tema Aesthetic
Moss, Dark, Light, AMOLED, Midnight, Sunset
🌐
Import Embed
Embed dari YouTube, Instagram, TikTok, & lainnya
🚀
GitHub Deploy
Upload ke GitHub Pages 1 klik dari menu

📊 Statistik Koleksi

Statistik dihitung dari data lokal galeri.

🛠️ Teknologi

🐍 Python 3.8+ 🖼️ Pillow 📡 Requests 🎬 FFmpeg 📦 Catbox.moe 🌐 HTML + CSS ⚡ Vanilla JS 🐙 GitHub Pages
